# Orientações para as aulas

- Escreva os READMEs das aulas em português do Brasil. Apresente um conceito novo de cada vez e use exemplos que o estudante possa acompanhar nos arquivos do projeto.
- Inclua perguntas e respostas sobre **DDD e arquitetura hexagonal** no README de cada aula. Relacione as duas ideias com o código da aula. Para DDD, explore o significado dos termos do negócio e as regras do domínio. Para arquitetura hexagonal, explore quem define as portas, quem as usa e o que cabe aos adaptadores.
- Formule cada pergunta a partir de uma situação concreta da aula. Diga qual ação está acontecendo, dê um exemplo de entrada quando ajudar e indique o método ou arquivo que o estudante pode consultar. Se a pergunta envolver mais de uma etapa, descreva cada etapa na ordem em que acontece.
- Use respostas curtas em blocos `<details>` para que o estudante possa tentar responder antes de conferir. Introduza termos e padrões mais avançados conforme o exemplo precisar deles.
