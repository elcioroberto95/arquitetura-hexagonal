# Arquitetura hexagonal

Monorepo de estudos. Cada aula evolui um projeto pequeno e pode ser revisada em uma PR própria.

## Aula 1 · Lista de tarefas

O [serviço de tarefas](services/tarefas/README.md) permite adicionar e listar tarefas pelo terminal. Nesta aula, o foco é seguir uma operação do terminal até o armazenamento e identificar as portas que ligam o caso de uso aos adaptadores.
